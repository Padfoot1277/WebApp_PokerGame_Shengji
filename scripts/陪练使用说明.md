正式游戏内陪练（2026-11-08）

现在优先在网页或小游戏的房间准备界面点击“增加陪练 / 减少陪练”。每次添加一位到空位，按添加先后顺序移除；开局后不可增减。正式陪练由服务器直接驱动，不需要运行本机脚本，也不占 WebSocket 连接。自动完成准备、定主（能定就定，优先手牌多的合法花色）、攻改（能攻优先攻，否则能改就改）、扣底、出牌和有权限时开始下一小局。真人队友申请弃局时，陪练自动同意。

正式陪练策略升级：所有游戏内陪练均可在服务器内部读取全局手牌与底牌快照，按双方队伍推演本墩后续合法应对。打家以吃走分牌为目标，坐家以不让打家吃分、趁己方稳墩跑分为目标；比较出小牌保大、用最低成本抢墩、垫分或垫杂牌、逼对手花大牌，以及用小主把出牌权交给对家。保守甩牌按每位玩家真实持牌分别校验，不把不同人的牌拼成不存在的对子。扣底同时尝试清空短副牌门与保留其中可靠的 A、大对子，针对整个8张组合做交换改进。

搜索会裁剪候选并限制节点与耗时，重点推演当前这一墩；对后续牌局使用控制牌、牌型、剩余主牌和末墩抠底等评分，不保证全局最优，也不假设真人一定按推演出牌。全局额外信息不进入客户端快照；以下旧版独立客户端仍只使用自己的手牌与公开信息。

没有真人连接时暂停行动。24小时内无真人进入或操作的房间会清除牌局和回执；陪练自动动作不刷新期限，再进原房间号会开始新游戏。增减陪练和未过期牌局均可跨服务器重启恢复。

以下是此前本机三个独立陪练客户端的用法；它们与游戏内陪练相互独立，不要用旧脚本占满希望添加正式陪练的房间空位。决策实现现已共用 internal/bot，scripts/bot-policy 仅为兼容旧客户端的命令行入口。

双击项目根目录的 `重启三个陪练.cmd`。需要本机安装 Node.js 22+ 和 Go（版本遵循项目 go.mod）。命令先编译规则辅助程序，成功后关闭旧陪练并启动三个独立账号，固定连接 `ws://120.53.18.44:8080/ws` 的 `test` 房间。

保持窗口打开；关闭窗口或按 Ctrl+C 停止陪练。无需 SSH，不部署或重启服务器。身份保存在被 Git 忽略的 `release/bots/tokens.json` 中，不要分享此文件。首次使用会尝试导入之前临时脚本的身份，避免重复占座。正常情况下重复启动会恢复原座位；服务器清空身份后会重新注册，只有大厅空位才能入座，不会主动移走真实玩家。

三个账号为测试陪练1、测试陪练2、测试陪练3，自动入座、准备、评估定主/攻改、扣底、出牌，以及轮到自己时开始下一局。每个游戏动作发送前至少等待1秒；等待中状态变化会重新判断。断线后自动重连，未确认请求使用原编号恢复，避免重复执行。身份被其他客户端接管时停止抢占。

陪练采用启发式评分策略：先手比较单张、对子、各种长度的拖拉机及保守甩牌；甩牌仅在所有子结构都找不到未见同域大牌时列为候选。跟牌兼顾当前墩分、低成本抢墩、保留大牌、避免拆散对子和拖拉机。基于本局已公开的出牌，排除已见实体牌，并从跟不齐同域牌推断缺门；对手剩余张数和未见大牌用于粗略估计后手压制、缺门杀牌风险，队友胜算较高时送分，暴露的队友小牌可以主动盖住保护。另考虑长主吊主、保留最后一张主、清空短门、末墩控制及接近80分门槛时的抢分。只使用本人手牌和公开局面，不读取对手手牌；对队友能否最终获胜仍是估计，不保证最优。定主比较合法花色的主牌数量、强度、对子和拖拉机，手牌收益不足时跳过，强势花色有条件时锁主。攻改比较新旧主牌体系的手牌评分，队友持底时提高门槛；锁主不改花色，亮过的实体牌不重复使用。扣底采用宽度96的束搜索，组合选择8张，惩罚扣分，优先保留主牌、大牌及完整对子/拖拉机，并考虑清空短门。这些评分为启发式估计，不是胜率预测，尚未通过长期对局调参。跟牌复用后端 `ValidateHideCheck` 在本地检查合法组合，先构造高牌/低牌优先的完整结构跟牌候选，再最多枚举20万个组合或2秒，预算内选评分最高的合法牌；找不到合法牌则暂停并记录原因。外层进程超时仍为15秒。运行日志不会输出手牌或身份凭据。`release/bots/status-*.json` 可查看各账号的阶段、座位及在线状态。

当前命令不会自动拉取代码；修改规则后再次运行，会编译本机最新代码。应与服务器版本保持一致。游戏结束阶段会等待，不自动另建房间。



策略验证（2026-11-08）：新增公开记牌与缺门、保守甩牌、便宜抢墩、保护暴露队友及复杂结构跟牌测试；16个固定随机种子的完整牌局，覆盖硬主和花色主、2/5/10/A级牌，经真实后端逐手校验，共1084次合法出牌并全部完成。此结果证明这些样本的合法性和可运行性，不代表胜率提升幅度。记忆仅保存在各陪练进程中，按房间和小局重置；重启后从当前可见的上一墩重新积累，不推测丢失历史。重新运行根目录的重启命令后，新客户端记牌逻辑生效。
