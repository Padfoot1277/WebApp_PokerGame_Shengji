AppID 已配置为 `wx4988a982a35beb56`。本工程是原生 Canvas + TypeScript，不依赖 Cocos；现有 Vue Web 版与 Go 后端保留。

## 当前完成范围

- 横屏 Canvas 牌桌、触摸与滑动选牌。
- 创建/加入房间、昵称与服务地址编辑、四人入座准备。

## 你现在的操作

1. 在微信开发者工具选择“导入项目”。
2. 目录选择 `M:\升级扑克\minigame`，不要选择仓库根目录，也不要选择 src。
3. AppID 应自动读到 `wx4988a982a35beb56`，项目类型应为“小游戏”。
4. 项目配置把 dist 作为小游戏代码目录，已生成 `dist/game.js` 和 `dist/game.json`，点击编译。
5. 应出现“升级 · 好友房”的横屏大厅，有昵称、房间码、服务地址、创建/加入房间按钮。

无需在开发者工具中执行“构建 npm”；运行代码已经打包，不携带 node_modules。若重新拉取代码后没有 dist，请执行下面的构建命令。

## 启动电脑服务

双击仓库根目录的 `启动本地后端.cmd`，窗口会显示电脑 IPv4 地址并启动服务。保持这个窗口打开；关闭窗口会停止服务。已经运行时无需再次启动。

也可以在 PowerShell 中运行：

```powershell
cd M:\升级扑克
go run ./cmd/server
```

电脑当前检测到的 WLAN 地址为 `192.168.124.19`，客户端默认服务地址为：

```text
ws://192.168.124.19:8080/ws
```

IP 可能随 Wi-Fi 或重启改变。可用 `ipconfig` 查 WLAN 的 IPv4 地址，再点击大厅“服务地址”修改。手机与电脑要在同一 Wi-Fi；电脑须持续开机。不要在手机上填写 localhost 或 127.0.0.1，那指向手机自己。

本地调试如提示地址不是合法域名，可以在开发者工具的项目本地设置中使用仅供开发的“不校验合法域名、TLS 版本及 HTTPS 证书”选项；这不用于正式发布，也不能保证所有真机环境接受局域网 ws。若真机仍拒绝，下一步配置测试 WSS 域名，不反复放宽其他安全设置。

可在电脑浏览器打开 `http://192.168.124.19:8080/healthz` 检查服务，正常返回 `{"service":"shengji","status":"ok"}`。若此页正常而工具提示 `Cannot send network request to localhost`，先检查上述项目本地调试选项。客户端会对地址拦截给出提示并停止无效重试；普通网络故障最多自动重试 5 次。

若电脑防火墙弹出请求，只在你信任的私人局域网内允许当前服务访问；不要关闭整个防火墙。路由器的访客隔离、手机 VPN 等也可能导致设备无法互访。

## 第一次测试顺序

先验证开发者工具显示大厅，再点击创建房间，确认服务器有连接并显示座位。随后使用安卓微信扫码预览。四个玩家分别使用自己的设备/微信身份，加入同一房间码；四人准备后自动发牌。一个设备保存一个体验身份，不要在同一身份下模拟四名玩家。

若返回前台或重新进入后连接失败，先检查服务是否仍在运行、IP 是否变化；当前体验身份按服务器地址分别保存。更换地址可能得到新的体验身份。

## 构建与检查

```powershell
cd M:\升级扑克\minigame
npm ci
npm run check
npm run build
npm test
```

build 只生成 dist，不改变 Go 规则；微信开发者工具重新编译即可加载。脚本已处理 Windows 中文路径。测试使用模拟 wx 运行环境验证启动、触摸提交、请求编号及前台恢复；不等同于真实微信网络测试。

完整联机回归脚本 `tests/full-round.mjs` 会运行四份实际打包代码，通过模拟 wx 触摸操作连接真实后端。建议另开测试服务端口，避免使用正在人工试玩的房间：

```powershell
# 在仓库根目录的一个窗口启动测试服务
$env:ADDR=':18080'
go run ./cmd/server
# 另一个窗口执行，将 IP 换成当前电脑局域网地址
$env:SHENGJI_TEST_URL='ws://192.168.124.19:18080/ws'
node minigame/tests/full-round.mjs
# 增加实际定主、扣底、顺序跳过攻改流程
$env:SHENGJI_TEST_CALL='1'
node minigame/tests/full-round.mjs
```

脚本验证 100 次单张出牌、25 墩结算、前台恢复、下一局、空选牌拦截及同队弃局。定主模式使用真实随机发牌，极少数无人能定主的牌局会明确失败并要求重跑。此脚本不验证真实 Canvas 像素布局、微信 SDK、安卓网络及复杂出牌组合。
