# 升级 · 好友局测试版

本版用于**同一 Wi-Fi 内的微信小游戏预览测试**，不是正式发布版本。支持朋友入座、准备、整局出牌、结算、下一局及弃局。当前为开发体验身份，尚未接入正式微信登录。

## 主持人启动

1. 解压测试包到一个固定目录。双击 `START-SERVER.cmd`，保持窗口打开。它会启动后端并显示电脑 IPv4 地址；首次使用需在你信任的私人网络内按系统提示允许服务，不能关闭整个防火墙。
2. 如果已经有本项目后端在运行，不要再启动第二份。浏览器打开 `http://电脑IP:8080/healthz`，应显示 `status: ok`。
3. 微信开发者工具导入包内 `minigame` 目录，AppID 为 `wx4988a982a35beb56`，编译即可；包内已有打包代码，无需构建 npm。
4. 大厅的“连接设置”填写 `ws://电脑IP:8080/ws`。本地开发的域名校验选项由账号管理员手动配置；它不能替代正式 WSS 服务。
5. 点击“预览”，用已添加测试权限的微信扫码。代码更新后需要重新预览，旧二维码不一定包含最新版本。

## 邀请朋友

- 所有手机和电脑连接同一 Wi-Fi，避免访客网络隔离。保持电脑服务运行。
- 主持人创建房间并入座，从菜单复制房间码；朋友扫码进入当前预览版本，设置相同服务器地址后输入同一房间码加入。
- 四个独立设备／体验身份分别入座，四人准备后发牌。不要复制会话凭据模拟玩家。
- 游戏内“邀请好友”仅发起微信分享，不能据此判断对方已经入座。以牌桌实际出现好友为准。
- 清理微信缓存可能丢失体验身份；切回前台会自动重连。返回大厅保留座位，加入原房间可恢复。

## 这轮重点试玩

1. 33 张扣底手牌分两行：两行均能点选、取消和滑选，选中状态不遮点数；扣底必须选 8 张。
2. 一张王与级牌定主，顺序攻改、跳过、重新扣底。跳过不可在同一窗口反悔，亮过的实体牌不可重复亮主。
3. 单张、对子、拖拉机及甩牌；观察失败甩牌说明和实际裁剪出牌。队友可以阻止甩牌。
4. 看上一墩后返回，下一墩开始时不应卡在回放；点击出牌区域可展开完整出牌。
5. 切后台、短暂断网后恢复；不要重复点出牌，等确认。新旧连接不能相互挤掉。
6. 一人申请弃局不结束，同队第二人确认才结算；未完成墩不计分、不额外抠底。
7. 结算分数、抠底、双方升级、下一局操作者清楚；观战者可看公开结果，不能操作玩家座位。

发现问题请记录：房间码、局数、阶段、刚做的操作、期望与实际结果、手机型号／微信版本，以及截图。不要发送会话 token 或密钥。

## 已验证与边界

- Go 规则、身份、持久化、请求去重及重连回归；Web 回放与连接回归；小游戏触摸、预校验、弹层、回放、结算与隐藏记牌测试。
- 四份实际小游戏打包代码通过真实 WebSocket 跑单张整局、定主扣底整局、含对子整局；验证两行扣底、100 张出牌／108 张唯一、200 分总牌值、公开记牌、观战隐私、错误回合、断线恢复、下一局和弃局。
- 多个阶段以实际 Canvas 绘制生成并人工检查画面。这不等同于微信 SDK／四台安卓真机验收。当前仍需朋友实机确认触摸手感与分享流程。
- 本版未提供公网异地连接、未上传正式体验版、未完成正式微信身份接入。测试包不包含账号密钥、玩家存档或会话数据；换用新服务数据目录会创建独立体验身份环境。
